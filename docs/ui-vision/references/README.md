# Raster-Referenzen – Design Review 25.09.2026

Diese Liste dokumentiert die **exakten** vom Nutzer gelieferten Referenzen und ihre Bedeutung für das Zielbild.

## Originale

1. `F4B2B5A0-473F-48E7-BEB0-461E03093175.jpeg`
   - kanonisches NG-Monogramm
   - metallisch, tiefblau/cyan, starke Fasen, helle Kanten
   - Quelle für App-/EXE-Icon

2. `85A3C523-0443-43EF-9CBE-127055BF6B0A.jpeg`
   - Icon-System / Navigation / Design-Prinzipien
   - klare Silhouetten, konsistente Linienstärke, Blue Accent = aktiv

3. `403976A3-1ABB-4EA6-A41B-FED0CA39A7AB.jpeg`
   - Editor-Layout mit großer 3D-Ansicht, Objektliste, Inspector, Asset Browser, 2D-View und Log
   - wichtige Referenz für Toolbar-Dichte und Panelaufteilung

4. `34D1687A-14C0-4112-8FA3-AFFE525069C2.jpeg`
   - alternative Premium-Shell mit großem Hero-Viewport
   - wichtige Referenz für linke Weltstruktur, Objektbibliothek, Minimap und Tool-Docks

5. `9AE91D85-8415-41F4-AE44-29C1493A3F85.jpeg`
   - integrierte Gesamtvision
   - wichtigste Referenz für App-Shell, Kontextpanel, Suche/Filter, Projekt-/Exportbereich und Bottom Icon Strip

## Priorität bei Konflikten

1. NG-Monogramm aus Referenz 1 ist verbindlich.
2. Gesamtarchitektur aus Referenz 5.
3. Viewport-/Dock-Verhältnis aus Referenz 4.
4. Detaildichte/Toolbar/Inspector aus Referenz 3.
5. Icon-Prinzipien aus Referenz 2.

Die Repository-SVGs unter `../mockups/` sind die implementierbare Übersetzung dieser Rasterreferenzen.
