# 01 – Brand & Theme

## Marke

Produktname: **NextGen Editor**  
Kurzmarke: **NG**  
Claim: **Welten erschaffen. Ohne Grenzen.**

Das App-/EXE-Icon ist ein metallisches, dreidimensionales NG-Monogramm in Cyan/Blau mit dunklem Metallkern, hellen Kanten und starker Silhouette. Kein Flat-N, keine generische Würfelmarke.

Pflichtgrößen: **256, 128, 96, 64, 48, 32, 24, 16 px**. Kleine Größen werden silhouette-first vereinfacht.

## Zustände

- Normal: dunkle Fläche + dünner Border.
- Hover: +8–12 % heller, Border subtil cyan.
- Active: blauer Verlauf/Fill, Icon weiß.
- Selected: 1 px Blue/Cyan Border + leichte Innenaufhellung.
- Focus: klarer Cyan-Ring.
- Disabled: 42–50 % Deckkraft, kein Glow.
- Dirty: Amber-Punkt/-Balken.
- Error: lokal rot, nie großflächig.
