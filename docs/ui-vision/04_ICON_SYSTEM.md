# 04 – Icon System

## Grundstil

- 24×24 ViewBox
- 1.8 px Stroke
- Round Cap / Round Join
- klare Silhouette
- `currentColor`
- keine Mischung aus Emojis, Foto-Piktogrammen und Line-Icons
- gefüllte Flächen nur für Primärzustände/Warnsymbole

## Größen

Toolbar 22–24 px · Panel Header 16–18 px · Outliner 14–16 px · Inline 14–16 px · App Small Mark 16/24/32 px.

## Pflichtinventar

Datei: new, open, save, undo, redo, copy, duplicate, delete, export  
Transform: select, move, rotate, scale, focus, ground, local/world, snap  
World: terrain, brush, layers, material, water, sky, weather, light, biome  
Scene: object, outliner, asset-browser, visibility, lock, unlock, search, filter  
Gameplay: npc, spawn, portal, trigger, event, collision, block-walk, path  
System: playtest, project, settings, help, validate, minimap, lod

## Semantik

Neutral = secondary text · Hover = primary text · Active = cyan · Collision = purple · Warning = amber · Delete = red · Playtest/Success = green.

Die kanonischen SVG-Formen liegen in `src/app/resources/icons/nextgen-icon-pack.svg`.
