# UI Theme – v0.44.7

Das GUI verwendet jetzt ein einheitliches Farbschema aus **Schwarz, Grau, Blau und Weiß**.

- Hintergrund: nahezu schwarz / dunkles Blau-Grau
- Panels: dunkles Grau-Blau
- Eingabefelder: Grau-Blau
- Buttons und aktive Tabs: Blau
- Hover/Active: hellere Blaustufen
- Text: Weiß bzw. helles Grau
- Rahmen/Separatoren: neutrales Grau-Blau
- Entfernt wurden die bisherigen orangefarbenen, grünen und hellblauen Flächen als primäre UI-Farben.

Die Änderung betrifft ausschließlich das GUI-Theme und die bisher explizit gesetzten UI-Farben. Editor-/Map-Daten und Rendering-Farben der eigentlichen Karte werden dadurch nicht verändert.
